# Учебный датасет: Dota 2

Стенд для SQL-домашней работы: PostgreSQL 17 в Docker, семнадцать таблиц,
около 160 тысяч строк.

## Откуда взяты данные

Имена героев, предметов, рецептов сборки, команд, турниров, игроков и
стримеров взяты из игры и с профессиональной сцены — чтобы по датасету было
интересно считать и чтобы результат запроса можно было глазами проверить на
правдоподобие.

**Все числа выдуманы.** Статистика матчей, рейтинги, составы команд, даты
переходов, просмотры стримов и донаты порождены арифметическими формулами и
настоящих данных не отражают. Призовые фонды турниров и даты выхода патчей
приближены к действительности, остальное — нет. Никакой вывод о настоящих
игроках, командах и стримерах по этим таблицам делать нельзя.

## Запуск

    docker compose up -d --wait     # поднять стенд, схема накатится сама
    docker compose exec postgres psql -U student -d shop
    docker compose down -v          # погасить и стереть том

Порт наружу не публикуется: тесты и psql ходят внутрь через
`docker compose exec`. База `shop`, пользователь и пароль `student`.
Оба файла схемы смонтированы в `/docker-entrypoint-initdb.d/` и выполняются
при первой инициализации тома. Проверка готовности идёт по TCP, а не по
unix-сокету: пока работают init-скрипты, сервер слушает только сокет,
поэтому контейнер становится healthy лишь после того, как данные залиты.

## Детерминированность

В `schema/02_seed.sql` нет ни `random()`, ни `now()`, ни `current_date`:
только `generate_series`, арифметика по модулю и явные списки значений.
Повторная заливка в чистый том даёт те же строки до единого значения, что
проверено сравнением `md5(string_agg(...))` по всем семнадцати таблицам.
Часовой пояс зафиксирован (`TZ=UTC`, `ALTER DATABASE shop SET timezone`),
иначе приведение `timestamptz` к `date` зависело бы от настроек клиента.

## Что заложено в данные

- **Стримеры и команды.** Шестнадцать стримеров имеют непустой `player_id`:
  это те, кто и стримит, и выступает. Цепочка
  `streamers → players → team_members → teams` с условием `left_at IS NULL`
  отвечает на вопрос «кто из стримеров за какую команду играет сейчас».
  У остальных двадцати четырёх `player_id` пустой — повод для `LEFT JOIN`.
- **Рецепты предметов.** Дерево сборки доходит до четырёх уровней
  (`Guardian Greaves → Mekansm → Headdress → Ring of Regen`), циклов нет,
  обход требует `WITH RECURSIVE`.
- **Согласованность показателей.** Позиция в слоте задаёт уровень `gpm`
  (кэрри зарабатывает вдвое больше саппорта), `net_worth` растёт с
  длительностью матча, победившая сторона имеет больше убийств и меньше
  смертей, саппорты набирают помощь и умирают чаще ядер.
- **Пропуски и перекосы.** В 2020 году турниров нет вовсе; четыре патча
  не связаны ни с одним турниром; 143 стрима остались без донатов;
  герои разобраны неравномерно — от 381 до 449 раз.
